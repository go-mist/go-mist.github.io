---
title: Define a table
description: Put columns on a struct and the table name on Table.
---

Columns live on a struct. The table name lives on `Table()`.

```go
package schema

import (
	"time"

	"github.com/go-mist/mist"
)

//go:generate mist generate

type User struct {
	ID        int64     `mist:"id,pk"`
	Name      string    `mist:"name,notnull"`
	Email     *string   `mist:"email,unique"`
	CreatedAt time.Time `mist:"created_at,notnull,defaultnow"`
}

func (User) Table() mist.TableMeta { return mist.TableMeta{Name: "users"} }
```

A tag is `mist:"column,type,modifiers"`. The type can be left out when the Go type is in the table below. The first modifier then follows the column name: `mist:"name,notnull"`.

| Go type | SQL type |
|---|---|
| `int64` | `bigint` |
| `int32` | `integer` |
| `int16` | `smallint` |
| `string` | `text` |
| `bool` | `boolean` |
| `time.Time` | `timestamp` |
| `[]byte` | `bytea` |
| `*T` | the same type, and the column is nullable |

`pk`, `notnull`, and `identity` make the column not null, so the field is `T`, not `*T`.

| Modifier | Effect |
|---|---|
| `pk` | primary key |
| `notnull` | `NOT NULL` |
| `unique` | unique. `unique=name` sets the constraint name |
| `default=expr` | `DEFAULT expr`. Wrap the segment in double quotes when the expression contains a comma |
| `defaultnow` | `DEFAULT now()` on a time column |
| `references=table.column` | foreign key. `ondelete` and `onupdate` are `cascade`, `restrict`, `set null`, `set default`, or `no action` |
| `length=n` | length of `varchar` or `char` |
| `precision=p` `scale=s` | precision of `numeric` or `decimal`. `precis=p.s` is the same pair |
| `generated=expr` | stored generated expression |
| `identity` | database-assigned integer. See below |
| `enum=name` | enum type name. The SQL type is `enum` |

Write the SQL type when that table is not the column you want: `timestamptz`, `varchar`, `uuid`, `jsonb`, `json`, `numeric`. `json` and `jsonb` use `json.RawMessage`. On MySQL, `bool` is `tinyint` and the field is `int8`.

## Auto-increment

`mist:"id,pk"` is a `bigint` primary key. Nothing fills the next value.

| Database | Tag | Column |
|---|---|---|
| PostgreSQL, HighGo, KingbaseES | `id,bigserial,pk` | `bigserial` |
| PostgreSQL, HighGo, KingbaseES | `id,bigint,pk,identity` | `bigint GENERATED BY DEFAULT AS IDENTITY` |
| MySQL, MariaDB | `id,bigint,pk,identity` | `bigint AUTO_INCREMENT` |
| SQLite | `id,integer,pk` | `integer` primary key, the rowid. The field is `int32` |
| SQL Server | `id,bigint,pk,identity` | `bigint IDENTITY(1,1)` |
| Oracle | `id,bigint,pk,identity` | `NUMBER(19) GENERATED BY DEFAULT AS IDENTITY` |
| Dameng | `id,bigint,pk,identity` | `BIGINT IDENTITY(1,1)` |

`bigserial` is rejected on MySQL. `identity` is rejected on SQLite. On Oracle and Dameng, `bigserial` alone is only the number type. `serial` is `int32`, `smallserial` is `int16`.

Leave that column out of `Insert` so the database assigns it.

`Table()` may return `pg.TableMeta` or `mysql.TableMeta`. Those generate that dialect's columns and codecs. `mist.TableMeta` generates `mist.Col` and no codec. One directory uses one of the three.

This describes the table. It does not create it.
